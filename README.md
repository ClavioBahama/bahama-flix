# bahama-flix

Plataforma de streaming Bahama Flix (Next.js).

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Estrutura

- `app/` — rotas
- `components/` — componentes
- `contexts/`, `hooks/`, `lib/` — suporte
- `netlify.toml` — configuração de deploy
